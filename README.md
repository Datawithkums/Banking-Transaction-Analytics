# Banking Transaction Analytics

## Project Overview

This project analyzes a banking transactions dataset using Python and Pandas to identify transaction patterns, monitor transaction performance, and explore fraud-flagged records.

The analysis focuses on transaction volumes, transaction status, transaction types, state-wise activity, and key business insights.

## Tools Used

- Python
- Pandas
- CSV data analysis
- PyCharm

## Dataset

The project uses the Indian Banking Transactions dataset covering transaction records dated from 2019 to 2024. The dataset contains 550,000 rows and 20 columns.

**Note:** Dataset values are treated as supplied records. Fraud flags are not independently verified, and the currency unit has not been confirmed.

## Key Business Findings

- **Total Transactions:** 550,000
- **Successful Transactions:** 506,247 (92.04%)
- **Fraud-Flagged Transactions:** 4,873 (0.89% of all records)
- **Most Frequent Transaction Type:** UPI
- **State with Highest Transaction Volume:** Maharashtra

## Project Outputs

The analysis generates CSV reports for:

- Banking KPI summary
- Transaction status analysis
- Transaction type analysis
- State-wise transaction analysis
- Fraud-flagged transaction analysis
- Business insights summary

## Disclaimer

This project is for analytical learning and portfolio demonstration. Fraud flags represent labels in the dataset and should not be interpreted as independently confirmed fraud cases.
